**KSRTC Ticket Management System**

Overview
A console-based Java application that simulates ticket booking and fare calculation for KSRTC buses operating between major stops from Bidadi to Mysore.
The system allows the driver to enter depot and bus details, choose routes, generate tickets with distance and fare, and track total earnings.
________________________________________
Features 
•	Route selection using short codes (B, R, C, MU, MN, S, MY)
•	Automatic distance and fare display
•	Ticket generation with date and time
•	Depot summary with total earnings
•	Option to continue or terminate program
________________________________________
Technologies Used
•	Java
•	Scanner class for input
•	LocalDateTime API for date and time
•	Switch-case for routing logic
________________________________________
How It Works
1.	Driver enters bus number, depot number, and driver ID.
2.	Gender selection determines route flow.
3.	User selects starting and ending location.
4.	System calculates distance and fare.
5.	Ticket is printed in formatted layout.
6.	Total earnings are updated and displayed when entering depot.
